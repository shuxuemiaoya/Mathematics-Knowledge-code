# Heading Expected Result Prompt

根据提供的原始不可变目录，输出修改和规范化层级后的预期正文标题列表。只返回 Markdown。

## 规范化规则：
1. **添加标题前缀**：为每一行目录项都添加正确的标题前缀，不能有任何裸文本或列表项符号（如 `- #` ❌，应该直接是 `#`、`##` 或 `###`）。
2. **层级分配**：
   - 章（如“第一章”、“Chapter 1”等）以及独立的索引、后记、附录（如“部分中英文词汇索引”、“后记”、“附录”等） → H1 (`#`)
   - 节（如“1.1”、“2.1”等） → H2 (`##`)
   - 子项（如“1.1.1”、“阅读与思考”、“探究与发现”、“信息技术应用”、“小结”、“复习参考题”、“文献阅读”等） → H3 (`###`)
3. **去除页码和导引符**：必须完全删除所有的尾部页码和页码导引符（如“…… 1”、“... 36”、“258”、“．． 10”等），只保留标题名称本身。例如：
   - `第一章 集合与常用逻辑用语 …… 1` 转换为 `# 第一章 集合与常用逻辑用语`
   - `1.1 集合的概念…… 2` 转换为 `## 1.1 集合的概念`
   - `阅读与思考 集合中元素的个数 …… 15` 转换为 `### 阅读与思考 集合中元素的个数`
4. **保留转义字符**：如果原始目录的标题中含有 markdown 转义反斜杠（如 `\*`），你必须原样保留在输出中，绝对不能将其删除或修改。
5. **格式要求**：不要输出任何其他说明文字，也不要包含任何虚假的目录标题（如“# 目录”或“# 修改后的目录”等），直接输出转换后的标题列表。不要返回 Python、JSON、Markdown 代码围栏。
