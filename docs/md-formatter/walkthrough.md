# 企业级 Markdown 格式化引擎重构总结

您之前手写的两套 Python 脚本已经成功重构为了工业级的排版引擎，并无缝集成到了自动化流水线中。以下是本次升级的核心技术点：

## 1. 架构升级：面向对象 (OOP) + 预编译正则

> [!TIP]
> 性能提升：新引擎采用类继承结构（`BaseFormatter`, `TextbookFormatter`, `ExerciseFormatter`），并将原来在循环内部实时编译的正则操作全部替换为 `re.compile()` 预编译加载。由于您有大量的特殊符号和中文字符规则判断，这能够极大提升对上百页长文档的清洗速度。

- `BaseFormatter`: 提供底层通用的 `**` 加粗屏蔽、多行公式合并转换以及公式兼容替换。
- `TextbookFormatter`: 集成了您之前针对**教科书**设计的特调规则，包括图注、复杂表格合并、行首空行处理以及 Callout 特殊标记替换。
- `ExerciseFormatter`: 包含了**习题册**专属解析分离与高亮，甚至我将原本被注释掉的“一数特调”和“必刷题特调”都解除了注释，做成了可以通过指令切换的子模式。

## 2. 工具化与模块化集成

我们废弃了之前必须要手工去命令行使用 `input()` 输入路径的落后模式，开发了功能完备的 `md_formatter` 标准库，支持：

### 方式一：流水线全自动执行
我在 `mineru_apps/batch_parser/main.py` 主程序中增加了 `--format` 参数。
现在，当您通过 MinerU 批量拉取了题库或教材后，程序会自动在这个输出文件夹上跑一轮您指定的清洗规则。例如：
```bash
python main.py "C:\测试文件夹" --format textbook
```
这就实现了**“上传提取 -> Markdown 下载 -> 企业级深度排版修正”**一条龙全自动。

### 方式二：独立命令行工具
如果您想单独对某些过去积压的文件夹进行清洗，可以直接调用这个包：
```bash
# 执行习题特调
python -m md_formatter.cli --dir "C:\你的目录" --mode exercise

# 针对一数的特调模式
python -m md_formatter.cli --dir "C:\你的目录" --mode yishu
```
