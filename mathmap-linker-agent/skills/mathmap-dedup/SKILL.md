# MathMap Multi-Tier Deduplication & Merging Specification (`mathmap-dedup`)

本技能规范定义了向 `mathmap` 知识图谱链接新书或试卷时的**多层级语义去重与合并机制**。

---

## 1. 去重与合并四级策略矩阵 (Policy Matrix)

| 资产层级 | 存储路径 | 去重与合并行为 | 判定标准与极界条件 |
| :--- | :--- | :--- | :--- |
| **Tier 1 单题 (`questions/`)** | `mathmap/习题/questions/Q*.md` | **归一化重用 + 解析追加** | LaTeX 公式与格式变体（如 `\frac` vs `/`，`\le` vs `\leq`，多余空格）归一化后**完全一致**时，复用既有 `Q*.md`；若新增题目带有解析，将其放入 `answers/Q*A2.md` 并更新嵌入。<br>**单字符敏感**：若题干措辞、数值或符号存在**1 个字符差异**（如数字改变或 `>` 与 `\ge`），必须判定为**不同题目**，保留独立 `Q*.md`。 |
| **Tier 2 题型整理 (`题型整理/`)** | `mathmap/习题/题型整理/*.md` | **严格语义合并 + 链接求并集** | 在同一小节或知识点下，对题型标题与考法意图进行严格语义匹配（相似度 $\ge 0.85$ 或核心概念重合）。匹配成功时，将候选题型中的独立题目链接 `![[mathmap/习题/questions/Q...]]` 补充并集嵌入既有题型笔记，上层引用重定向至该既有题型。 |
| **Tier 3 题集框架 (`题集/`)** | `mathmap/习题/题集/*.md` | **绝不合并 (隔离)** | 套卷、单元测试、月考、刷真题等框架总集笔记代表特定的试卷/教辅结构，**严禁合并**。冲突时自动追加 `<book_short>_` 书短名前缀隔离。 |
| **知识点挂载 (`知识点/`)** | `mathmap/知识点/*.md` | **宽泛归类挂载** | 采用四级宽松映射机制（手工映射表 $\rightarrow$ 章目录表 $\rightarrow$ 去编号精确匹配 $\rightarrow$ 子串与同义词模糊匹配），确保新题型归纳挂载到既有 `mathmap/知识点/*.md` 节点，严禁盲目新建同义知识点 md 文件。 |

---

## 2. 运行与诊断命令

### 2.1 独立预览去重与合并计划 (Dry-run Plan)

```bash
python3 scripts/mathmap_dedup.py <vault_root> <source_book_dir> <book_short> --out dedup_plan.json
```

### 2.2 执行链接与去重合并 (Integrated Link & Merge)

```bash
python3 scripts/link_to_mathmap.py <vault_root> <source_book_dir> <book_short>
```

## 3. 核心验证与契约准则 (Core Verification Directives — 必遵)

1. **同知识点异内容链接与标注准则**：
   - 当新书/教辅涉及已有知识点，但讲解内容或题型整理不同时，**严禁覆盖或删除既有知识点文本**。
   - 必须通过 `![[mathmap/习题/题型整理/...|显示名]]` 链接挂载到既有知识点节点（`mathmap/知识点/*.md`）的 `# 题型` 章节，且必须在 **`## 来源：<书短名>`** 独立标题下分类标注来源。

2. **多概念组合知识点切分与新建准则**：
   - 若既有知识点节点属于粗粒度的多概念组合节点（标题包含 `_` 或 `及`/`与` 组合词），而新文件将该内容切分为独立精细的知识点（如 `空间直角坐标系` 与 `空间向量运算的坐标表示`）：
   - **严禁强行合并回粗粒度旧组合大节点**。必须在 `mathmap/知识点/` 中**建立全新的独立知识点 md 节点**，并将精细题型挂载至新节点，推进知识图谱精细化演进。

3. **同题干异解析关联与来源标注准则**：
   - 当新题目的题干与既有题目（`mathmap/习题/questions/Q*.md`）归一化后完全一致时，**不重复创建 `Q*.md` 节点**。
   - 若新题目附带了新的解析内容，仅将其解析文件复制到 `mathmap/习题/answers/`（重命名为 `Q*A_<书短名>.md`），然后追加嵌入至既有 `Q*.md` 节点，并**明确标注解析来源**：
     `![[mathmap/习题/answers/Q*A_<书短名>|解析来源：<书短名>]]`。

---

## 4. 幂等与质量校验 barrier

1. **题目节点不冗余**：对于同一道题目的不同排版版本，`questions/` 目录下 `Q*.md` 文件数**不增加**。
2. **字符微差异不误杀**：stem 改变数字或符号的变体题目**必须保存为独立 `Q*.md`**。
3. **题型节点链接并集**：合并后的 `题型整理/*.md` 包含合并前两者的所有题目链接，且不产生重复 `![[...]]` 行。
4. **知识点挂载纯新增**：挂载行只增不改，完美兼容 `## 来源：<书短名>` 分组。
