# Data Acquisition Agent 架构与规范

## 1. Agent 角色定义
- **Agent Name**: `data-acquisition-agent`
- **定位**: 专注于 K12 与高等数学教学资源、试卷、课件、同步习题的自动化获取、嗅探与规范化目录归档。

## 2. 目录拓扑规范
所有获取的资料统一遵循三层标准教学结构：
```text
[学段/册名] (如 必修一 / 必修二 / 选修一)
└── [大章序号与名称] (如 第一章 集合与常用逻辑用语)
    └── [小节序号与标题] (如 1.1 集合的概念)
        └── [资料名称] (如 集合的概念（答案解析）.pdf)
```

## 3. 技能列表 (Skills)
- `smartedu-downloader`: 智慧教育平台 (basic.smartedu.cn) 教材同步习题下载与归档引擎。
