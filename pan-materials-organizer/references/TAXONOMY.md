# 网盘教育资料分类与目录结构规范指南 (TAXONOMY.md)

本指南是网盘资料整理与文档归类的核心标准。任何 Agent 或自动化分类脚本在对文件/文件夹进行识别、移动与重组时，必须严格遵守本规范。

---

## 核心原则 0：原子文件单元保护（防拆分铁律）

在初高中教辅体系中，**“一个文件”往往表现为一个成套书籍的子文件夹**。
- **典型原子文件夹示例**：
  - `/高中/数学/课堂同步/教辅/一数/常规版2026电子版/`
  - `/高中/数学/课堂同步/教辅/金版教程/2025-2026《金版教程》导学案-数学-选择性必修第一册-A版/`
  - `/初中/数学/课堂同步/教辅/必刷题/2026 八上必刷题 北师大数学/`
  - `2026版《初中必刷题》数学 RJ 7上/`（内含正文PDF、批注答案PDF、狂K重点PDF）
- **原子单元判定标准**：
  若一个文件夹代表**某一学期/某一版本的单本教辅、试卷套系或特定讲义专题**，其内部仅为该书的“主书正文、答案解析、重点册、配套课件”，则该文件夹为**不可分割的原子教辅单元 (Atomic Material Unit)**。
- **强制约束**：
  归类移动时必须将该文件夹作为一个整体迁移至目标品牌或模块目录下，**绝对禁止将其内部拆散成孤立文件散落**！

## 一、 第一层：学段与顶层分类（Root Layer）

网盘根目录下仅允许存在以下 4 个顶层目录：

| 目录名 | 收纳范围与职责 | 严禁放入 |
| :--- | :--- | :--- |
| `高中/` | 全日制普通高中所有统考学科资料（高一、高二、高三、高考） | 初中、小学、综合读物、非学科软件工具 |
| `初中/` | 初中各年级所有学科资料（七年级/初一、八年级/初二、九年级/初三、中考） | 高中、小学、杂项工具 |
| `小学/` | 小学各年级学科资料（1~6年级、小升初） | 初中、高中资料 |
| `其他/` | 跨学段综合资料、课外读物、网课视频、工具软件、备份文件及未分类文件 | 明确属于某学段某学科的纯教材/教辅 |

### 1. `高中/` 允许学科列表

`数学/`、`语文/`、`英语/`

## 三、 第三层：学科核心功能架构（标准必设四大目录）

**所有学段的每一个学科下，均统一建立且必备以下 4 个标准子目录：**

1. **`课堂同步/`**：日常学期教学、同步练习、同步测评与配套讲义；
2. **`课本/`**：各出版社官方电子教材（如人教版、北师大版、苏教版等）；
3. **`总复习/`**：初中/高中升学大复习（中考、高考一轮/二轮/冲刺）；
4. **`其他/`**：该学科专属的特色或拓展资料（如数学的思维方法、公式总结、强基奥数、创新课件、论文期刊等未归入前三类的学科资料）。

---

## 四、 第四层：核心功能模块内部标准规范（`课堂同步/` 与 `总复习/`）

在每个学科的 **`课堂同步/`** 和 **`总复习/`** 内部，均统一标配以下 5 个标准分类子目录：

| 子目录名 | 收纳标准与职责说明 |
| :--- | :--- |
| **`教辅/`** | **必须且仅能以具体教辅品牌名称建档**（如 `53/`、`必刷题/`、`万唯/`、`天星教育/`、`金版教程/` 等，详见第五节品牌库）。严禁使用宽泛模糊命名。 |
| **`试卷/`** | 各阶段单元卷、月考卷、期中期末试卷、联考模考卷、历年真题分类试卷（纯卷与解析卷）。 |
| **`专题/`** | 题型强化训练、解题技巧突破、重难点/拉分题攻坚、专项突破书册。 |
| **`讲义/`** | 名师教学案、教师备课教案、机构辅导讲义、知识点精讲文档。 |
| **`其他/`** | 不属于上述四类但属于该阶段同步或复习范畴的教学拓展素材。

## 六、 智能决策分类流（分类决策引擎逻辑）

当 Agent 或脚本面对一个待归类文件/文件夹时，执行如下判断链：

```
[待归类项: 文件夹或文件]
           │
           ▼
[Step 1: 原子性检查 (Atomicity Check)]
是否为独立单本教辅套系文件夹 (如: 一数/常规版2026、必刷题/2026八上北师大)？
├── 是 ──► 保持整体不拆分，将其整体视为最小归类单元
└── 否 ──► 进一步识别其是否为跨科目压缩大包 (若是则逐一提取子文件)
           │
           ▼
[Step 2: 规则与关键词特征匹配 (Heuristic Match)]
从名称中提取：学段(高/初/小) + 学科(语/数/外/理/化等) + 功能模块 + 品牌名
├── 匹配成功且高置信度 ──► 归入对应路径（如: 高中/物理/课堂同步/教辅/必刷题/）
└── 无法直接提取/信息模糊 ──► 进入 Step 3
           │
           ▼
[Step 3: LLM 语义推理决策 (LLM Semantic Reasoning)]
将待归类项名称、父目录背景、内部采样文件名作为输入，调用 LLM 综合推理判断：
- 推理其教育阶段（高中/初中/小学）
- 推理其对应学科（数学/物理等）
- 推理其功能性质（课本/试卷/教辅/讲义等）
├── LLM 推理判定成功 ──► 移入对应标准化目标路径
└── LLM 判定置信度不足或判定为“非学科杂项” ──► 进入 Step 4
           │
           ▼
[Step 4: 安全降级收容 (Fallback to Unclassified)]
移动至：全部文件/其他/未分类/
绝不强行猜测，杜绝污染正式学科库！
```
