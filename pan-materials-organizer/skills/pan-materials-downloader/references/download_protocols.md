# 网盘教辅高速下载与本地归档协议指南

由于百度网盘与夸克网盘在网页端均对 50MB~100MB 以上大文件设置了“请使用官方客户端下载”的弹窗拦截，本指南提供经过验证的突破方案与规范化下载协议。

---

## 1. 突破大文件拦截的两种有效方案

### 方案 A：Aria2 RPC / 多线程直链下载
1. **原理**：
   在网页端获取文件的真实下载直链（包含 `sign`、`timestamp`、临时 Token）后，通过携带用户会话的 `Cookie`（主要包括 `BDUSS`）和指定的 `User-Agent`，调用本地 `aria2c` 或 Python 流式分块下载，完全不经过浏览器原生下载器，因此不会触发客户端弹窗拦截。
2. **Aria2 RPC 典型配置**：
   - 默认地址：`http://127.0.0.1:6800/jsonrpc`
   - 参数：分块数 `--max-connection-per-server=16`，多线程 `--split=16`，支持断点续传。

### 方案 B：云端一键归纳 + 官方客户端高速批量拉取
1. **原理**：
   利用 `baidu-pan-organizer` 或 `quark-pan-organizer` 将分散的文件在云端汇总至单个根文件夹（如 `/数学妙呀/未分类/2026-2027人教A数学合集`）。
2. 用户在 Mac/PC 官方客户端中仅需对该根文件夹点击一次“下载”，享受官方 VIP/SVIP 的最高速度，避免在网页端重复手动确认几十次。
3. 下载完成后，运行 `local_archive_organizer.py`，一秒将下载目录内的文件自动分拣归类到标准教研拓扑。

---

## 2. 本地教研标准归档拓扑规范

下载后的所有初高中教辅，必须统一重组为符合知识图谱与教研大纲的五层规范结构：

```
[输出根目录]
└── 高中
    └── 数学
        └── 人教A版
            └── 必修第一册
                └── 2027_必刷题_人教A版_必修第一册
                    ├── 主书_2027《理想树•必刷题》（必修第一册）（数学）（人教A版）.pdf
                    ├── 狂K重点_2027《理想树•必刷题》（必修第一册）狂K重点.pdf
                    ├── 答案解析_2027《理想树•必刷题》（必修第一册）答案.pdf
                    └── 配套资源_2027《理想树•必刷题》（必修第一册）配套资源.pdf
```

每个归档目录必须生成 `materials_manifest.json`，记录每个文件的哈希值、原始网盘名称、标准化路径及文件角色。
