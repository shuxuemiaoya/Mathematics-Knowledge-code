# 夸克网盘初高中教辅智能整理技能 (Quark Pan Organizer)

本技能专职处理夸克网盘（`pan.quark.cn`）中分享的初高中数学及各学科教辅资源（53、必刷题、新高考真题合订本等）。

---

## 1. 适用场景
- 用户提供夸克网盘分享链接（如 `https://pan.quark.cn/s/xxxx` 及提取码）。
- 需要快速提取分享包中的初高中教辅并转存到个人夸克云盘。
- 需要在个人夸克网盘中对散落的初高中资料按学段、年份、学科建立体系化文件夹并移动归集。

---

## 2. 标准操作流程

### 阶段一：解析与打开分享页
1. 使用 `scripts/quark_pan_helper.py` 解析分享链接与提取码。
2. 通过 `chrome-devtools-mcp` 导航至目标夸克网盘链接：
   - 自动识别并填写提取密码；
   - 等待文件列表渲染完成。

### 阶段二：智能识别与多选保存
1. 运行教辅关键词嗅探（`数学`、`必刷题`、`53`、`高中`、`初中`、`人教` 等）。
2. 在浏览器端或通过夸克 API 勾选目标教辅文件夹/文件。
3. 触发“保存到网盘”，指定保存到夸克网盘的接收目录（如 `/教辅资料库/待整理`）。

### 阶段三：夸克网盘云端重组
1. 进入夸克网盘主界面 (`https://pan.quark.cn`)。
2. 按照教学标准创建层级文件夹（如 `高中/数学/2026-2027必刷题`）。
3. 执行批量移动，完成资源归纳。
