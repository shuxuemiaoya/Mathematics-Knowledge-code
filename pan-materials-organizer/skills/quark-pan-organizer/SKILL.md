# 夸克网盘初高中教辅智能归类技能 (Quark Pan Organizer)

本技能专职处理夸克网盘（`pan.quark.cn`）中的教育文档高精度分类、分享包转存、非数学资料分流与目录拓扑规范化重构。

---

## 1. 核心分类准则与规范

详细分类拓扑与各目录收纳定义请查阅：[TAXONOMY.md](../../references/TAXONOMY.md)。

1. **各级目录职责明确**：
   - 第一层：`高中/`、`初中/`、`小学/`、`其他/`
   - 第二层：学科（数学、语文、英语、物理、化学、生物、思想政治/道德与法治、历史、地理）
   - 第三层：`课堂同步/`（教辅、试卷、讲义、题库、专题）、`课本/`、`总复习/`、`公式总结/` 等
   - 教辅品牌：必须使用明确品牌（`53`、`必刷题`、`万唯`、`一本`、`天星教育`、`优化设计` 等），严禁宽泛容器。
2. **原子文件单元防拆分（套系完整性）**：
   - 包含正文、答案、狂K重点的套系单书文件夹（如 `/一数/常规版2026电子版`、`/金版教程/2025-2026导学案`、`/必刷题/2026 八上必刷题 北师大数学`）为不可拆分原子单元，移动时作为整体迁移，绝对禁止打散。
3. **双层决策与未分类降级**：
   - 规则无法判定时调用 LLM 推理判定；若仍无法判定，统一放入 `全部文件/其他/未分类/`。

---

## 2. 标准作业流程

### 阶段一：解析与抓取
1. 使用 `scripts/quark_pan_helper.py` 解析分享链接与提取码。
2. 打开分享页面，定位待转存文件。

### 阶段二：智能识别与分类调度
1. 调用 `scripts/classifier_engine.py` 进行原子性检查与规则匹配：
   ```python
   from classifier_engine import is_atomic_folder, match_taxonomy_rules, build_llm_classification_prompt, get_fallback_path
   ```
2. 判断分类目标路径：
   - 若命中规则：得到目标目录；
   - 若模糊未命中：根据 `build_llm_classification_prompt` 提供的提示词进行 LLM 逻辑推理；
   - 若 LLM 无法给出高置信度结果：自动分派到 `get_fallback_path()`（即 `全部文件/其他/未分类`）。

### 阶段三：夸克云端自动化归档
1. 调用夸克 Web 端 API 或驱动浏览器自动化操作；
2. 确保目标目录存在，执行 `file/move` 进行批量规整；
3. 输出归类整理日志。
