# Pan Materials Organizer & Downloader Contract

本工程专职处理百度网盘、夸克网盘中的初高中数学及其他学科教辅资料（必刷题、53、高考总复习、一课一练、试卷等）的定向转存、云端规整、自动化下载与本地标准教研层级归档。

## 1. 严格作用域隔离与数据安全
- **云端个人网盘操作安全**：严禁无差别清空或删除用户个人网盘中的非目标文件夹；云端目录新建、移动、重命名操作必须针对明确匹配的初高中教辅目录。
- **本地归档目录边界**：本地下载保存路径必须显式限定（如用户指定目录或项目标准 staging 目录），严禁随意覆盖已有同名文件，需做哈希或大小校验。

## 2. 核心支持平台与技能集成
1. **baidu-pan-organizer**：
   - 百度网盘分享提取码鉴权与 `sekey` 捕获；
   - 基于 `yunData` / Web API 的分享目录穿透遍历与批量转存；
   - 个人网盘教辅智能分类重组（按年份/学段/版本/书名自动归集）。
2. **quark-pan-organizer**：
   - 夸克网盘分享链接解析与云端批量转存；
   - 夸克网盘目录拓扑扫描与初高中教辅智能归集。
3. **pan-materials-downloader**：
   - 突破 Web 端大文件限制；
   - 支持直链多线程断点续传与本地 Aria2 RPC 调度；
   - 本地教学体系标准化目录结构自动归档与 `manifest.json` 溯源清单生成。
