# Heading Expected Result Prompt

根据提供的不可变目录和正文标题，说明完整的标题修改预期。只返回 Markdown。

必须且只能按以下顺序包含三个一级标题：

# 修改后的目录
# 标题修改明细
# 预期效果

在“修改后的目录”下，逐条列出预期标题。每一项都必须是包含完整 Markdown 标题行的项目符号，例如：`- ## 1.1 集合`。

在“标题修改明细”下，逐条列出建议修改，格式为：`原标题 -> 预期标题`。

在“预期效果”下，概述目录对齐、H1-H6 层级规范、高置信度 OCR 标题纠正及非目录标题降级后的效果。

目录是标题层级的唯一权威依据。不要虚构父级或章节上下文，不要改写教学正文。不要返回 Python、JSON、Markdown 代码围栏，也不要在三个规定章节之外输出任何文字。
