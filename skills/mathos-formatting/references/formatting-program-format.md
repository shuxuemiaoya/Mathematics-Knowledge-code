# Approved Formatting Program Format

Approved programs live under `plugins/approved/<plugin-id>/`.

Required files:

- `heading_rules.json`
- `content_cleaner.py`
- `metadata.json`
- `approval.md`
- `sample_before.md`
- `sample_after.md`

Newly approved programs start with `"allowed_scope": "manual-only"` in `metadata.json`.
