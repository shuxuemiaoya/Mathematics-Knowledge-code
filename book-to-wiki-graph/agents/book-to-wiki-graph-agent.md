# Book to Wiki Graph Agent

本 Agent 不限制学科、出版社、章节数量或组织层深度。

## 核心流程

1. 冻结 PDF 或 Markdown 来源；
2. PDF 完整转换为 Markdown；
3. 提取印刷目录并建立初始组织树；
4. 通读全书，将正文划分为知识点、例题、习题、情景引入四类原子；
5. 输出只有组织层和原子层两种节点的 Wiki Graph；
6. 校验来源覆盖、所有权、顺序及原子无外链约束；
7. 生成全书组织总图、逐章原子细图及可选的独立语义关系图；
8. 校验 Canvas 中的目录层级、直属归属、原书顺序、链接与计数。

组织笔记只保存标题与直属子节点链接。原子笔记是最小内容单位，不链接其他笔记。Canvas 层级从左向右、同级书序从上向下；分类只改变原子卡片标签和颜色，不改变排列。语义关系保存在 `book-graph.json` 并单独成图，不写回原子正文，也不混入组织图。
